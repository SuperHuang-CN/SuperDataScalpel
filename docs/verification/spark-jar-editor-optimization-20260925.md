## 模型所属数据源筛选专项（2026-09-25 补充）

- 保留“数据模型 / JDBC 数据源”资源类型，模型连接字段改为“模型所属数据源”，候选展示连接用途标签。
- `GET /api/v1/data-sources?hasPublishedModels=true` 使用已发布模型关联的 EXISTS 条件，在数据库分页前筛选 JDBC 连接；与原 Search DSL 条件 AND 组合，不改变普通查询行为。
- 模型输入允许 SOURCE / STORAGE，输出与读写要求 STORAGE；前端只查询已启用连接。逻辑注册在 SOURCE 的已发布模型仍可作为输入，不按连接名称排除。
- 历史配置不被静默替换；停用连接、未发布模型或用途不匹配会提示并阻止确认。JDBC 直接选表逻辑保留。
- 前端专项 14 个用例通过，TypeScript、限定文件 ESLint、Vite 构建通过（既有大包提示仍存在）。
- 后端专项 `ModelSourceCandidatesIntegrationTests` 2 个用例通过：已发布/草稿/停用、外部模型、用途组合、非 JDBC 排除、关键词、分页总数、去重、普通列表兼容和 OpenAPI 参数说明。
- 后端专项采用 test Profile 的 H2；仅模拟与本查询无关的任务产物存储及 PostgreSQL 专属权限初始化 Runner，使用测试认证上下文，未修改生产初始化逻辑。因现有 Admin 其他测试存在旧 Canvas 类型和构造器编译错误，使用 Wrapper 生成测试依赖、Java 21 单独编译专项测试，再由 Wrapper `compile surefire:test -Dtest=ModelSourceCandidatesIntegrationTests` 执行；不代表普通全量 test 已通过。
- 用户重启 Admin 后，在实际 8080 接口验证候选、关键词、分页和 `/v3/api-docs`；当前模型候选为 `mysql_0923_storage`、`pg_102_storage`，与实际已发布模型所属连接一致。两个 origin 无符合条件的模型，因此不在模型候选中。
- 8887 页面验证模型列表、关键词搜索、输出引用名自动生成和取消不保存；JDBC 输入候选仍为两个 origin，未受模型筛选影响。未保存任务变更，未启动作业或写入业务数据，未重启 TaskEngine。

## 已实现的范围

- 保存在线开发 / 上传 JAR 的开发方式，重新编辑恢复原选择；确认切换不删除源码或替换生效 JAR。
- 配置页与编辑器共用右侧资源抽屉；输入 / 输出 / 输入及输出只选择一次。模型按存储过滤，JDBC 按已配置数据源取表，不增加 Schema 二次选择。
- 资源绑定与本地样例参数在同一任务配置事务保存，不必通过“生成工程”才能保存。生成、重新生成、下载继续沿用真实开发包能力。
- 编辑器新增 / 修改绑定保留源码、运行参数与现有模式；保留历史多表绑定及抽样参数，移除多表选择前明确确认。
- 新增独立“检查代码”操作，只编译检查，不保存源码或替换 JAR；应用与试运行保持原有执行链路。
- 插入完整读取 / 打印代码；写入明确为需补全的模板。Kafka 不提供同步 `show()` 打印操作。
- 离线 JetBrains Mono、局部 Monaco 配色、编辑实例模型隔离、插入撤销边界、过时检查诊断丢弃。
- Task Engine 管理独立 JDT LS 子进程，浏览器全部经 Admin 中继；一次性连接凭证、登录有效期、会话上限、队列限制、断线保留与回收。没有新建独立业务服务或要求部署 Nginx。
- 真实语义重命名，编译、批流 Trial、开发包源码路径和 Maven 入口使用实际类名。

## 真实语言服务验证

- 官方 JDT LS 1.60.0 运行包 SHA-256 验证通过；两个独立进程的 SDK 补全、跨会话 completion resolve、重连、泛型方法链、悬浮、格式化、重命名、参数签名、自动导入、诊断以及工作目录回收测试通过。
- 实测发现 JDT 1.60 的诊断不带可选 version 字段，修正前端全丢弃问题：拒绝明确过期版本和未同步修改，兼容无版本推送。无版本诊断仍可能短暂反映上一次分析，不承诺严格的逐版本诊断一致性。
- 参数签名需显式开启 JDT 配置，已修正；协议失败发生在输入工作线程时仍等待子进程退出并回收目录，实际进程测试通过；初始化与关闭互斥，防止关闭后继续创建进程。
- JSON-RPC 浏览器传输 5 个用例通过；修复连接关闭时未完成请求不能退出的竞态。
- WebSocket 测试覆盖错误鉴权、重复连接、容量满、断线回收、非法协议；凭证测试覆盖一次性消费、登录过期、容量限制。
