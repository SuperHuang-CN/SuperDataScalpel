## 必须知悉的生产边界

1. 限流和并发按**单节点**计算，不是集群全局额度；令牌桶容量为一秒额度。运行内存指标重启清零，P95/P99 为滚动近似值。
2. 日志有界异步、有限重投，Kafka 持续故障/进程终止仍可能丢失，不是可靠持久化审计。未做 Kafka 长时中断、多节点故障切换、持续浸泡或极限容量测试。
3. IP 策略使用 TCP 对端地址，不信任 X-Forwarded-For；前置代理场景需按真实拓扑配置。流式超限终止前，较早的请求字节可能已到上游，不提供请求回滚。
4. 新增运行策略和有效期以网关数据库为准，普通同步保留，删除重建/切换 Provider 不自动迁移。备份应包含网关自己的 schema。
5. 未建设主动探活/故障摘除、多上游权重、告警通知平台、分布式配额、通用 CORS/Header 改写或自助订阅审批；不应把本轮交付称作这些功能已经具备。
6. 非 local/test 环境将拒绝默认或过弱管理凭据，部署前必须提供合规密码、JWT 密钥及机器 Token。
