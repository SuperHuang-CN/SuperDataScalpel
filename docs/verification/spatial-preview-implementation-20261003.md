# 空间预览实施验收（2026-10-03）

本记录对应已实现的应用接口与页面，区别于此前独立原型实验。使用根 `start-local-dev.sh` 启动现有 local 环境，复用 8080/8887、管理库、192.168.5.102 的 PostGIS 和现有对象存储；未另起 Mock 系统。完整规则见[统一预览设计](../design/model-management.md#spatial-preview-design)。

## 已交付

- 数据库：模型详情 → 数据预览 → 空间预览。
- 文件：文件数据集详情 → 数据表 → 选择逻辑表 → 空间预览。
- 自动准备和定位，准备时仍可操作地图；连续平移缩放取消旧请求、保留视口，过时响应不覆盖新画面。
- 完整概览先显示，放大补局部图片；重叠范围和有效代次复用缓存。临时渲染繁忙/本地副本恢复时先用概览，再有界补取细节。
- “重新加载数据”实际重读来源并切换代次。文件追加/替换/删除、CRS 及已知模型任务写入使旧代次失效；未知外部写入按 10 分钟新鲜期或手动刷新处理。
- 原始 GDB ZIP 无包裹目录可直接上传；GDB/SHP 缺少明确 EPSG 时保留文件，确认 CRS 后继续解析。

## 2026-10-04 首次加载全链路优化

本轮不提前生成地图产物。每轮强制创建新预览代次，实测完整读取、绘图、传输、共享副本保存及页面操作；未清空数据库/操作系统缓存。新上传文件自然复用解析阶段的物化文件，不把这称为预先生成地图。仍使用根启动脚本和同一开发环境，无新增框架或服务。

### 改动与效果

- PostGIS 预览专属连接改用二进制 WKB 传输，保留单条只读查询及 256 条游标批次；32 MiB 活跃批次保护不改变其他 JDBC 查询。独立同 SQL、同百万要素对照：网络读取量约 2.56 GB → 1.29 GB，读取 28.079 → 13.725 秒，WKB 字节数与 CRC 完全一致。保留 32 MiB 保护的复测为 15.871 秒；未采用实测反而变慢的自适应批次。
- GeoPackage/GeoParquet 只投影几何列，避免无关属性解码；文件几何直接传入写入器，省去 Geometry→WKB→Geometry 的重复转换，3857 来源跳过恒等投影。写副本同时计算 SHA-256，省掉完整文件的再次扫描。WKB 写入/绘图改用紧凑双精度坐标序列；冻结百万副本三轮交替对照中绘图中位数 7.653 → 5.788 秒，写入与绘图累计少分配约 4.16 GB 临时对象，WKB、索引及 PNG 摘要一致。
- 完整来源、完整概览及版本校验成功后即可显示地图；大副本继续保存，完成后同代次转 READY，地图不清空、不重新定位。来源读取或概览生成失败仍不得显示部分结果。其他节点只在完整副本可用后恢复细节，恢复重试有界。
- 连续刷新留下的旧大副本按当前有效代次回收。实测曾遇 MinIO 磁盘 97% 使用率、507 拒绝保存；完整百万概览依然 HTTP 200、未截断。修复旧代次回收后空闲从 2.11 GiB 恢复到 14.21 GiB，随后三轮百万均成功到 READY。此故障记录保留，不计入成功性能轮次。

百万表的完整 WKB 为 1,270,409,310 字节，首图仅 314,856 字节；三轮 PNG SHA-256 与本轮优化前完全一致。优化前同表首图需等待全部副本，三轮为 49–60 秒（下节保留原始分阶段记录）；本轮首图中位数减少约 54%。这属于同一开发环境的前后观测，源库缓存、存储空闲和系统负载会影响耗时，不能把全部收益都归因于单一算法。百万表真实非空局部首绘约 1.4–1.7 秒，重复范围为 18–36 ms。

真实浏览器另验得百万表点击重载至地图实际出现约 25.3 秒；副本保存期间平移缩放、重复点击重载保持同一代次。转 READY 后保留视口及单个地图画布，无闪空、无页面错误，后续细节成功补入。

## 2026-10-04 百万表概览超时修复

用户反馈的失败已由现存日志确认：2026-10-03 21:08:34，`SpatialPreviewFiles.render → SpatialPreviewPngRenderer.render → SpatialPreviewService.build` 在生成完整概览时触发 **30 秒预算**，来源读取已完成。原错误把不同阶段都显示为“预览处理超过时间预算”，无法直接判断失败点。

本次修改集中在原有热路径：完整概览将百万次 `RandomAccessFile.seek/read` 改为 1 MiB 缓冲顺序读取；局部图保留随机定位。绘图复用 `BasicStroke`，每个环直接追加到最终路径，保留原抗锯齿、洞、线宽及屏幕精度规则。没有提高预算、抽样或跳过要素。准备状态和日志新增分阶段信息，后续超时明确显示所在阶段。

## 明确边界

- 默认最多 100 万条记录、2 GiB WKB、120 秒来源读取；这几个条件需同时满足。复杂单体、异常坐标和过密视口还有各自保护。完整准备失败不会发布截断前缀。
- 超限时保持属性入口并提供现有空间服务入口；没有自动复制到专用库、发布/预热千万级服务的功能，也没有对现有 GeoServer 进行大数据承载压测。
- 数据湖、其他空间数据库、RAR/UDBX/MDB、栅格、曲线及三维不在本次支持范围。原上传和解压大小限制没有提高。
- 多 Admin 使用共享状态和对象产物的代码路径及恢复行为已有测试；本次未做多节点实际集群、弱网、长时间持续负载及客户生产库容量压测。

主要验收脚本、逐请求 JSON 和截图在本地 `.local/spatial-preview-implementation/`；不作为产品依赖。源测试文件未改写，原有业务表未修改。保留百万复杂面和无索引 10 万条测试模型供继续查看，其余临时样本按本次测试记录清理。
