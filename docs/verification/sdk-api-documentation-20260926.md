# 在线 SDK API 说明验证（2026-09-26）

状态：功能已实现，并在用户重启后的开发环境完成只读联调。设计与维护规则见 [SDK 设计](../design/spark-jar-task-sdk-v1.md#在线-sdk-api-说明)。

## 实现范围

- 编辑区右上角 SDK API 入口；右侧抽屉先显示中文用途、调用示例，重载和参数按需展开，支持搜索、用途分类、复制及后续返回类型跳转。
- SDK 源码签名与中文 Javadoc 经 JDK Doclet 自动生成资源，随 SDK 构建交付；目前 26 个类型、101 个方法/常量/字段访问器。不存在前端方法清单或独立文档服务。
- Engine 读取配套 SDK 资源，Admin 通过已有 Engine 客户端转发；认证、错误和 OpenAPI 沿用现有机制。文档读取不依赖语义服务就绪，不调用用户源码。
- SDK 更新构建部署后，打开抽屉、手动刷新或打开期间的 30 秒刷新读取新内容；版本及 SHA-256 内容指纹明确指向部署版本，不把未发布源码当作已可用 API。
