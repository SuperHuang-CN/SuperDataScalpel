# 文件数据集异步解析阶段四：管理端

## 页面结构

文件数据集详情包含基础信息和解析参数、逻辑表、Schema、数据预览、当前来源以及文件列表。
解析参数根据后端 `parsingOptionsLocked` 禁用。

支持表级装载的格式展示“追加数据”和危险操作“全量覆盖”。来源列表仅展示已经生效的数据：
来源名、顺序、记录数、生效时间、下载、替换和删除。

## 异步反馈

`currentLoadJobId` 用于控制轮询、按钮禁用和“已就绪 · 正在追加/覆盖”提示。初始解析失败后空表
和临时文件自动消失，具体错误在解析队列抽屉查看。

解析队列展示 Job 类型、装载方式、目标来源、数据集/表/文件名称快照、状态、尝试次数、租约和
错误摘要。来源列表不展示失败记录，也不提供来源重试。

覆盖、替换和删除确认框必须说明操作不可恢复、旧对象立即删除，以及已排队或运行的 Canvas 任务
可能失败。Excel/GDB 隐藏表级装载入口并引导使用整文件替换。
