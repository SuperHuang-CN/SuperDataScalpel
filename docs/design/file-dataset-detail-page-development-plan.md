# 文件数据集详情页

## 1. 页面结构

详情页采用多 Tab：

- 基础信息与解析参数；
- 逻辑表列表；
- 文件列表；
- 解析队列。

选择逻辑表后展示 Schema、数据预览和当前来源。页面继续使用 Ant Design 和 TanStack Query，
不引入额外全局状态。

## 2. 基础信息

名称、目录和描述始终可编辑。解析参数由后端 `parsingOptionsLocked` 控制：存在文件、表或非终态
Job 时禁用；数据集清空后恢复编辑。

## 3. 表与来源

表列表展示状态、来源数、总行数以及当前装载提示。支持格式提供追加和全量覆盖；Excel/GDB
隐藏这些入口。

当前来源页签只显示已经生效的来源，包括来源名、顺序、记录数和生效时间，并提供下载、替换和
删除。页面不展示装载过程记录或未生效记录。

## 4. 异步状态

`currentLoadJobId` 非空时每 2 秒刷新详情，显示“已就绪 · 正在追加/覆盖”并禁用冲突操作。
初始失败后表和临时文件自动消失，错误在解析队列查看。队列抽屉展示业务名称快照，即使业务记录
已经清理仍可定位失败。

## 5. 危险操作

全量覆盖、来源替换和删除使用确认框，明确说明：

- 操作不可恢复；
- 成功后旧对象立即删除；
- 已排队或运行的 Canvas 任务可能因对象不存在而失败。

## 6. 查询与测试

详情查询按数据集、表、文件、来源和 Job 分离 Query Key。成功提交装载后刷新表、文件和队列；
有活动 Job 时启动轮询，终态后停止。

测试覆盖按钮可见性、解析参数锁定、Job 轮询、失败表消失、来源下载/替换/删除和危险确认文案。
