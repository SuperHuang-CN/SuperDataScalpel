# 常用字段模板详细设计

## 定位

常用字段模板用于减少模型字段的重复录入，是建模效率工具，不是标准数据元、码表或模型字段的主数据来源。模板可以只包含一个字段，也可以包含一组经常共同出现的字段，例如审计字段组、数据接入字段组和业务日期字段组。

第一版采用“选择时复制快照”的轻量语义：

```text
常用字段模板
      │ 选择并复制
      ▼
模型字段草稿 ──人工调整──► 保存模型字段 ──按现有流程──► 物理变更计划/显式建表
```

- 模板字段复制到模型后获得模型自己的字段 UUID，允许自由修改和删除。
- 模型字段不保存模板 ID；模板修改、停用或删除不会传播到已有模型。
- 选用模板只改变前端尚未保存的模型字段草稿，不直接调用字段保存、物理变更计划或 DDL 接口。
- 标准数据元以后作为独立的强治理资产设计；第一版不把模板升级为带版本传播和偏差审批的标准体系。

## 功能范围

第一版支持：

- 全局模板，不按项目、目录或数仓分层重复维护。
- 单字段模板和字段组模板使用同一结构，由字段数量自然区分。
- 可自由填写的扁平分类文本；不新增分类实体、目录树或通用标签框架。
- 模板编码、名称、分类、说明、排序和启停。
- 每个模板 1—100 个有序字段。
- 字段编码、名称、平台类型及参数、Geometry 定义、可空、主键、排序、说明和可选码表绑定。
- 从可编辑的 `MANAGED` 模型字段页一次选择多个启用模板并复制。

第一版不支持模板 Excel 导入导出、使用次数统计、模板来源追踪、模板版本历史、自动同步、字段默认值、自增、生成列、索引或数据库专属存储参数。

## 持久化模型

### 模板头 `ds_model_field_template`

| 字段 | 说明 |
| --- | --- |
| `id`、`created_at`、`updated_at` | 继承 `BaseEntity` 的 UUID 与审计时间 |
| `code` | 全局唯一模板编码，保存时大写化，最长 64 |
| `name` | 模板名称，最长 100 |
| `category` | 可空扁平分类文本，最长 100 |
| `description` | 可空说明，最长 500 |
| `sort_order` | 模板展示排序，0—9999 |
| `enabled` | 是否允许新选用 |
| `content_version` | 模板头与字段集合的内容版本；修改时用于并发冲突校验 |

### 模板字段 `ds_model_field_template_item`

| 字段 | 说明 |
| --- | --- |
| `template_id` | 模板 UUID 标量引用；模板删除时由 Service 显式清理 |
| `code`、`name` | 字段编码和名称；编码保存时小写化，并在模板内唯一 |
| `field_type` | 统一 `PlatformDataType` |
| `field_length`、`numeric_precision`、`numeric_scale` | 字符串或精确小数参数 |
| Geometry 四元组 | `geometry_kind`、`crs_authority`、`crs_code`、`coordinate_dimension` |
| `nullable`、`primary_key` | 可空和主键候选 |
| `sort_order` | 模板内部稳定顺序 |
| `description` | 字段说明快照 |
| `standard_dictionary_id` | 可选码表 UUID 标量引用 |

模板与字段属于同一个强生命周期聚合，但仍按工程约定只保存 UUID 标量，不建立 JPA Entity 关联。新增和修改在一个管理数据库事务中原子保存模板头和全部字段；任一字段失败不留下空模板或部分字段。

## 校验与码表一致性

- 模板编码使用字母开头的字母、数字和下划线；字段编码使用同样语法并小写化。
- 主键字段不可为空；Geometry 不可作为主键，第一版只接受 EPSG 与 XY。
- `DECIMAL` 必须有 1—38 的精度，小数位不得大于精度。
- 模板内小写化后的字段编码不能重复。
- 新绑定码表时，码表必须启用，并按现有码值校验字段类型、长度、精度、范围和小数位。
- 已绑定码表停用后允许模板原样保留或解除，不能把它新绑定到其他模板字段。
- 模板字段参与码表引用保护：被模型字段或模板字段引用的码表都不能删除、改变编码/取值类型或删除、改码节点；新增码值会同时验证模型字段和模板字段是否能够安全表达。
- 码表详情分别展示模型字段引用数和模板字段引用数；现有“引用字段”明细仍只列真实模型字段。

## API 与权限

| 方法 | 路径 | 权限 | 说明 |
| --- | --- | --- | --- |
| `GET` | `/api/v1/model-field-templates` | `model.view` | 使用统一 Search DSL 分页查询，并批量返回字段快照 |
| `GET` | `/api/v1/model-field-templates/{id}` | `model.view` | 查询模板详情 |
| `POST` | `/api/v1/model-field-templates` | `model.update` | 原子新建模板及字段，创建后默认启用 |
| `POST` | `/api/v1/model-field-templates/{id}/actions/update` | `model.update` | 按内容版本原子替换模板信息及字段集合 |
| `POST` | `/api/v1/model-field-templates/{id}/actions/enable` | `model.update` | 允许新选用 |
| `POST` | `/api/v1/model-field-templates/{id}/actions/disable` | `model.update` | 禁止新选用，不影响已有模型 |
| `POST` | `/api/v1/model-field-templates/{id}/actions/delete` | `model.update` | 删除模板元数据，不影响已有模型 |

查询可按模板自身的 `code`、`name`、`category`、`enabled`、`sortOrder` 和审计时间使用 Search DSL 筛选排序。列表以唯一模板分页，Service 对当前页一次批量读取模板字段和码表摘要，避免 N+1。

第一版复用模型权限，不新增模板专用权限：查看模型的人可以查看和选用模板；能够修改模型字段的人可以维护模板。码表选择器仍要求 `standard.dictionary.view`，无该权限时已有模板码表绑定只读保留。

## 模型侧复制规则

模型字段页仅在模型字段结构可编辑且不是 `EXTERNAL` 模式时显示“从模板添加”。选择弹窗只查询启用模板，并同时读取当前模型目标数据存储的平台类型能力。

多个模板按模板列表顺序、模板内字段顺序展开，执行以下规则：

1. 字段编码统一按小写比较。
2. 与模型现有字段重复，或所选模板之间重复的字段，只保留先出现项，后出现项明确列为跳过。
3. 目标数据存储明确不支持该字段的平台类型定义时跳过，并展示方言能力原因；检查不仅覆盖类型大类，也覆盖有界/无界字符串以及 Geometry 的几何类型、CRS 和坐标维度。
4. 模板绑定的码表已停用，或当前用户没有 `standard.dictionary.view` 时仍复制字段，但码表绑定留空并给出警告。
5. 可复制字段追加到模型字段末尾，重新按 10 的步长生成展示排序；不沿用模板字段 UUID 和模板内部绝对排序值。
6. 复制完成后只进入模型页面的未保存状态；用户可以逐字段修改，再明确点击“保存字段”或按现有受管物理表流程生成变更计划。

若目标类型能力尚未加载或加载失败，页面不能把未知解释为支持；确认按钮保持不可用并显示错误。复制过程不请求后端创建模型字段，因为真正的权威校验仍在现有模型字段整体保存接口执行。

## 前端交互

“模型管理”菜单调整为“模型列表”和“常用字段模板”两个子入口。模板管理页采用紧凑管理表格，支持名称/编码、分类和状态筛选；列表展示单字段/字段组、字段预览、状态和更新时间。

新建和修改使用抽屉：模板基本信息位于上方，字段使用可增删的紧凑卡片编辑。字段类型变化时只保留适用参数；码表选项按类型族过滤。抽屉存在未保存内容时关闭会二次确认。

模型字段页的选择弹窗支持模板或字段关键词、分类和多选。下方持续显示可添加数量以及冲突、不支持类型和停用码表处理结果，避免静默丢失。

## 生命周期和演进边界

- 停用只阻止新选用，不修改或扫描模型。
- 删除模板没有模型侧引用保护，因为模型不持久化模板关系；确认文案必须明确已有字段不受影响。
- 模板更新无需生成模型 Schema 版本，也不访问外部 JDBC。
- 模型字段真正保存后，继续由现有服务递增模型 Schema 版本并决定直接保存或物理变更计划。
- 后续若引入标准数据元，可以让模板字段可选引用标准数据元，并在复制时把 `standardDataElementId` 带入模型字段；不能反向把复制语义改成模板自动传播。

## 验收要点

- 单字段和字段组均可新增、修改、筛选、启停和删除。
- 模板头和字段更新原子提交，重复字段、非法类型参数和不兼容码表被拒绝。
- 停用模板不出现在模型选择器中；删除、修改模板不影响已有模型字段。
- 多模板复制稳定处理与已有字段及模板间的编码冲突。
- 目标数据存储不支持的字段定义（包括类型参数和空间参数）不进入草稿，停用码表绑定留空，所有跳过或降级都有可见提示。
- 模型字段排序重新追加，字段可继续独立编辑和保存。
- 选用模板、维护模板都不调用物理表端口；只有模型既有显式建表或物理变更操作可以执行 DDL。
