# DSH 聊天附件

适用：工程插件 `0.5.0`、DSH `0.1.5-rc.1`。本次扩展系统助手的聊天输入与历史，沿用 Admin 和插件 Bridge，不修改 DSH 核心，不改变系统 MCP 的文件接口范围。

## 使用与边界

在聊天输入区点击“添加附件”、拖入文件或粘贴截图。文件自动上传，发送前可预览、移除或重试失败项；全部上传成功后可以只发附件，也可以附带文字。发送成功清除本次草稿，失败保留。切换会话、关闭抽屉及站内跳转保留各会话草稿，浏览器刷新或退出清除未发送草稿。历史保留附件卡片，支持预览和下载；归档后仍可读取。

支持 xlsx、xls、csv、tsv、txt、md、json、yaml、yml 和 PNG/JPEG/WebP/GIF，每条最多 5 个、单原文件最多 5 MiB。普通文本需要 UTF-8。其他类型明确拒绝，不显示成已可供 AI 读取。

图片使用 DSH 原生 image 块。模型明确声明不支持图片时，界面提示并禁止发送，插件在入队前返回 422 `BRIDGE_MODEL_IMAGE_UNSUPPORTED`。未知能力交给原生适配器处理，不宣称已经识图，不自动接 OCR 或切换模型。

Excel 复用 Apache POI，保留工作表、行号、单元格地址和格式化值。公式使用文件中缓存的结果，不重新计算公式或执行宏；合并单元格保留实际锚点值，不自动填充。最多 100 个工作表、20000 个有效行、100000 个单元格，xlsx 解压后最多 32 MiB。文本或 Excel 解析结果最多 1 MiB，超限明确拒绝，不截断后假装完整。

## 链路与持久化

浏览器使用现有 JWT 请求 Admin。Admin 从登录身份确定用户、检查会话归属、验证类型并解析文件，再用 Bridge 凭据上传 DSH。客户端不能指定用户、远程 URL、内部路径或原生附件引用。

原文件、规范化图片和解析结果通过 `ctx.attachments` 持久化。插件仅保存当前用户、会话下的上传凭证与原生引用；知道原生摘要不能绕过归属。附件不放在普通 `workspace_write` 可覆盖的目录。

控制域保持版本 1，采用兼容扩展：JSON 存储将新声明的附件表初始化为空，消息新增可选附件字段，旧记录继续可读。原生会话继续保存消息事实，控制记录用于恢复原文及附件卡片，不向浏览器输出模型内部文件地址或解析内容。升级前可备份 DSH_HOME；旧插件写入会丢弃它不认识的新增元数据，回退须恢复配套备份，不能只降级包版本。

文件以原生 file 块和当前会话附件 UUID 提交模型。新增 `attachment_read` 工具，只读当前会话已发送文件的解析内容；每次最多 12000 个 UTF-16 字符，返回 offset、nextOffset、hasMore 和总字符数，模型按需继续读取。图片以原生 image 块提交。附件内容属于用户数据，不提升为系统指令。

输入框移除附件只撤销本次发送引用。已上传对象随 DSH_HOME 保留，本期不增加永久删除或原生存储垃圾回收。

## 接口

Admin 前缀 `/api/v1/dsh`，Bridge 前缀 `/bridge/v3/users/{userUuid}`；v1/v2 验证入口保留纯文本契约。

| 接口 | 行为 |
| --- | --- |
| `POST /sessions/{id}/attachments` | `{clientAttachmentId,name,data}`，data 为标准 Base64；201 返回 ID、名称、媒体类型、大小、种类和图片尺寸，不启动模型 |
| `GET /sessions/{id}/attachments/{attachmentId}` | Admin 返回原文件字节、媒体类型及下载文件名；认证请求，禁止缓存；Bridge 内部使用有界 Base64 JSON |
| `POST /sessions/{id}/messages` | `{clientMessageId,text,attachmentIds}`，文字和附件至少一个；202 表示持久化接收 |
| `GET /sessions/{id}/messages` | 用户消息新增可选 attachments 摘要，分页及游标语义保持 |
| `GET /capabilities` | 新增 chat-attachments 和附件的扩展名、数量、大小及模型视觉支持情况 |

上传 UUID 与内容绑定，可安全重试同一次上传。消息去重覆盖文字和有序附件 ID；接收结果不确定时先同步历史，不用新标识自动重发。跨用户/跨会话附件返回 404，归档禁止上传或发送。

普通请求限额保持，仅上传入口 Admin 使用 8 MiB 边界、Bridge 使用 9 MiB 边界（含 Base64 和解析内容），单文件仍为 5 MiB。预览通过认证下载生成临时 Blob URL，不把令牌放到 URL，不开放 Markdown 外部图片。

## 验证与部署

插件测试覆盖上传去重、归属拒绝、归档、视觉能力拒绝、分段读取及历史原文恢复；前端执行 TypeScript 和相关 ESLint，后端生产代码编译。Excel 测试覆盖 xls/xlsx、稀疏单元格、缓存公式、UTF-8、损坏文件和超限。

更新插件镜像和 Admin 后生效。系统开发环境仍只通过根 `./start-local-dev.sh` 启动，不另起临时服务。上传成功不能代替真实模型的读表或识图验收。
