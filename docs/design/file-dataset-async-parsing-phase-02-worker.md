# 文件数据集异步解析阶段二：Worker

## 执行模型

Worker 领取 `FILE_PREPARATION` 或 `TABLE_SOURCE_VALIDATE` Job，并在事务外执行对象读取、归档物化
和全量校验。领取与结果提交分别使用短事务。

领取时核对：

- 文件准备：`file.currentPreparationJobId == job.id`；
- 表校验：`table.currentLoadJobId == job.id`；
- 文件、表和数据集标量引用一致；
- 文件状态和物化信息满足任务类型要求。

任务运行期间发送心跳并延长租约。瞬时对象存储错误自动重试；格式、Schema 和数据内容错误不
重试。过期租约由恢复器重新排队，尝试耗尽时进入终态失败。

## 成功与失败

初始校验成功时原子创建权威字段和首个来源。追加在末尾创建来源；全量覆盖替换全部来源；单来源
替换原地更新目标记录。

最终失败统一清除匹配的当前 Job：

- 初始空表直接删除；
- 后续装载保留当前数据；
- 无引用临时文件、原始对象和物化目录立即删除；
- 对象删除失败只记告警。

过期结果不得覆盖当前状态。Worker 已生成但尚未发布的物化目录由对应准备服务直接丢弃。

## 安全限制

预览抽样与全量校验使用不同大小限制。全量校验必须扫描弱结构格式的全部记录，确保预览窗口以后
出现的非法值也会使 Job 失败。
