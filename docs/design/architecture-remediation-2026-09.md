## 第一批：行为正确性

- [x] 实时 START/STOP Outbox 顺序；Dispatcher 持久化 stop-before-start 防护，迟到 START 不产生外部作业。
- [x] 超时结果与外部终止/清理责任分离；取消失败、提交结果不确定时继续恢复、终止并确认。
- [x] 同一数据服务部署/移除串行协调；旧操作不能覆盖新状态或撤销新路由，外部调用保持在数据库事务外。
- [x] 文件表空 ID 表示未引用；Canvas 文件引用持久化索引随定义更新，存量索引恢复与损坏定义有明确处理。

## 第二批：工作量可控

- [x] Dispatcher 仅分页处理到期观察/清理项；已清理历史不再进入周期扫描；失败采用退避。
- [x] 明确 Outbox、执行恢复与 Dispatcher 阻塞任务的调度归属，限制单轮工作量及并发。
- [x] 本体读取复用单请求解析和关系索引，批量读取模型元数据；分页列表避免逐项扫描全库，保持现有 API 输出语义。
