# 本体总览 V1

状态：已实现。本文说明业务建模“本体总览”的当前产品行为、数据边界和实现约束；实际人员与部门样例见[验证记录](../verification/business-ontology-v1-personnel.md)。

## 目标与边界

本体总览用于浏览最近保存的业务对象类型及其关系。画布节点是“人员、部门、水库”等对象类型，连线是一份业务关系定义；具体人员、水库记录仍由对象详情的数据预览按需读取。

总览是只读结构视图。对象和关系继续在对象详情页维护，不保存画布位置，不创建业务对象或关系数据副本，也不执行能力或 Action。

## 数据流

```mermaid
flowchart LR
    A[对象类型当前定义] --> B[GET /business-object-types/graph]
    C[当前引用投影] --> B
    B --> D[目录与已应用筛选]
    D --> E[X6 只读类型画布]
    E --> F[按需读取对象详情]
    E --> G[按需执行静态配置校验]
```

`GET /api/v1/business-object-types/graph` 一次返回对象类型库的轻量结构快照。节点只包含基础资料、主来源摘要和计数，关系按原定义方向返回，并以关系 UUID 去重。接口不读取来源业务表，不运行全类型健康检查，也不返回完整属性或能力定义。

调用者只有 `ontology.view` 时仍可浏览对象与关系，但主来源模型名、模型编码及关联字段名、字段编码为空；这些元数据仅在同时拥有 `model.view` 时补充。前端没有 `model.view` 时不渲染字段元数据查询组件，也不开放配置校验和数据预览入口。

## 页面结构

业务建模列表工具栏提供“列表／本体总览”切换，默认仍为列表。`view=graph`、`focusId`、`directory`、`keyword` 和 `enabled` 保存在 URL，刷新、复制地址以及从详情返回时可恢复浏览范围。

左侧复用 244px 目录面板。“目录”按父子目录范围筛选，“对象”列出当前已应用范围内的对象类型；点击对象进入以它为中心的一跳聚焦视图。查询条件由查询按钮或 Enter 提交，目录切换立即应用已提交条件。

中间画布使用 220×112px 对象卡片，展示名称、编码、主来源、属性数、分组数、启用状态和配置校验状态。停用对象灰化；主动带入筛选范围外的邻居显示“范围外”。关系按定义方向绘制箭头，标签显示正向名称和数量约束；悬停或选中后显示正反向访问名称。自关联使用自环，同一对类型的多条关系使用错开的路径。

右侧详情默认关闭。选择对象时按需读取对象详情，展示基本信息、来源与身份、属性分组和仅登记的业务能力；选择关系时展示两端访问、反向数量含义和身份映射。工作区宽度小于 1000px 时使用 360px 覆盖式 Drawer，使画布可用宽度不会被固定详情栏压到 640px 以下。

## 浏览和布局

默认画布展示筛选范围内的全部对象以及两端均可见的关系，孤立对象同样保留。聚焦视图包含中心对象和直接邻居；“展开关联”只加入一跳邻居，不递归读取整张关系网。主动带入的范围外对象不改变原目录和查询条件。

同屏上限为 80 个对象类型。筛选范围超过上限时画布不截取前 80 个，而是提示从左侧对象列表选择焦点；聚焦或展开达到上限时显示未展示数量并要求重新聚焦。

自动布局以关系的无向邻接结构划分连通分量，再从确定性根节点分层排列；聚焦对象作为所在分量的根。箭头仍表达业务方向，循环关系不按 DAG 处理。拖动位置只存在于当前页面会话，扩展邻居时尽量保留已有节点位置；修改筛选、改变焦点或主动重新布局时重新计算。

## 导航与诊断

对象详情的“可访问关系”提供“在本体总览中定位”。有未保存修改时，用户可以保存后前往、放弃修改前往或取消。关系详情的编辑／查看入口始终返回关系原始所属对象，并通过 `tab=relations&relationId=...` 定位同一份定义。

总览初次加载统一显示“未校验”和“来源可用性：未检查”。用户选中对象后可调用现有 `validation` 接口检查结构和引用；`health` 在 V1 中同样是静态配置诊断，不表示来源连接或实时健康。

## 当前限制

- 不保存共享布局，不提供画布内编辑或批量建模。
- 不展开属性、来源模型、能力或具体业务记录为图节点。
- 不进行递归关系探索、全图搜索索引或服务端图查询。
- 80 节点容量、多关系错线、失效引用和停用节点均有实现保护；当前开发库只有人员、部门两个启用样例，尚未用大规模真实类型库完成视觉压力验收。

## 2026-09 读取成本

兼容现有列表和详情响应，每次请求对类型定义进行一次解析，建立关系计数、关系 UUID 所属者和访问编码索引；一页内各对象共用该快照。模型与字段仅按本页来源及其直接关系目标批量读取，缺失或未发布的来源仍逐位置给出原有诊断。当前完整诊断仍需要一次全类型定义快照，成本为全库定义一次遍历加本页相关关系处理，不再对每行重复解析整库；并未引入跨请求缓存。
