# 数据源图标素材

素材均随前端打包，本地引用，不依赖运行时外网请求。

- PostgreSQL、MySQL、Microsoft SQL Server：Devicon `v2.17.0` 的 `*-original.svg`，保留原始品牌路径及颜色。来源：<https://github.com/devicons/devicon/tree/v2.17.0/icons>，许可见 `DEVICON-LICENSE`。商标权归各品牌所有。
- `database.svg`、`plug.svg`、`hierarchy-2.svg`：Tabler Icons `3.35.0` 的 outline 图标，保留原始矢量，用 CSS mask 跟随文字颜色。来源：<https://www.npmjs.com/package/@tabler/icons/v/3.35.0>，许可见 `TABLER-LICENSE`。

用途与品牌是两套语义：插头表示数据源接入，圆柱表示数据存储，分支节点表示数据分发；目录名称不能决定品牌或用途图标。
